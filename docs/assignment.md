# Take-home assignment brief

Website: https://takam.mof.gov.il/

Identify a business or operational problem in how information on the Takam Directives website is presented or consumed, and develop a software solution that addresses it. The assignment assesses development skills, engineering thinking, independence, and the ability to plan and implement an end-to-end solution. AI capabilities are optional.

## Part A: Problem identification and solution planning
- **The problem:** What challenge did you identify, who does it affect, and why is it worth solving?
- **The solution:** What do you propose to build, and how does it address the problem?
- **The technical design:** What are the main components, the architecture, and the technologies you chose?

## Part B: POC development
Build a working solution with a limited subset of the site's data.
- End-to-end implementation: organized code, a logical separation of components, and a basic UI that lets someone try the solution.
- Quality and testing: several relevant test scenarios, including edge cases.
- Ability to run it: clear install and run instructions, code kept separate from configuration, and no sensitive credentials.

## Part C: Engineering thinking and production readiness (answer in the README)
1. Engineering decisions and quality: the main design considerations, what you chose not to implement, and one significant change that would improve maintainability or scalability.
2. Deployment and operations: how to adapt the solution for automated deployment in an organization, how to verify that a deployment succeeded, and one significant failure scenario, including how to detect and diagnose it.
(Infrastructure, CI/CD, and production adaptations do not need to be implemented.)

## Guidelines
- Recommended time: 4–6 hours. A production-ready solution or polished UI is not expected.
- AI tools are encouraged, but you must understand and be able to explain the code and your decisions.
- Choosing the scope, prioritizing, and deciding what to leave out are part of what is assessed.

## Submission
- Source code: a repository link (or ZIP) with the code, sample data, and an example config file.
- README: problem and solution, architecture, install and run instructions, tests, and the Part C answers.
- A video of up to 3 minutes showing the solution in action and how it solves the problem.
